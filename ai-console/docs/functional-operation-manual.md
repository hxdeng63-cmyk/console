## 1. 系统概述

AI 控制台是一套面向道路交通智能分析场景的综合管理平台，基于 Vue 3 + TypeScript + Element Plus 构建。系统采用「顶部 Tab 导航 + 左侧侧边栏」的双导航布局，支持实时监控、事件检测、设备管理、智能联动、算法配置等核心能力。

### 1.1 系统布局

- **顶部导航栏**：实时监控、事件统计、事件管理、布控管理、文件分析、控制台
- **左侧侧边栏**（控制台内）：超级管理员、用户中心、设备管理、智能联动、系统设置、算法管理、固件中心、预警事件、数据清理
- **主内容区**：根据当前路由展示对应页面内容

### 1.2 账号角色

| 角色 | 说明 |
|------|------|
| 超级管理员 | 拥有系统全部权限，可管理菜单、资源、授权等 |
| 管理员 | 拥有大部分管理权限 |
| 普通用户 | 拥有查看和部分操作权限 |
| 访客 | 仅拥有查看权限 |

## 2. 登录与退出

### 2.1 登录系统

1. 打开系统地址，进入登录页面。
2. 在「登录账号」输入框中输入用户名。
3. 在「密码」输入框中输入密码。
4. 点击「登录」按钮进入系统。

**注意事项：**
- 登录账号和密码为必填项。
- 密码输入框支持显示/隐藏切换。
- 按 Enter 键可快捷触发登录。

### 2.2 退出系统

点击页面右上角的用户头像或退出按钮，选择「退出登录」即可安全退出系统。

## 3. 顶部导航模块

### 3.1 实时监控

实时监控页面提供视频画面预览和交通数据实时展示。

#### 3.1.1 监控墙模式

- **主视频区**：展示当前选中通道的实时视频画面，支持 FLV 协议播放。
- **预览通道**：选择不同的视频通道进行切换。
- **绘制区域**：点击「绘制区域」按钮可在视频画面上绘制检测区域。

#### 3.1.2 实时交通参数

右侧数据面板展示以下实时数据：
- 平均速度（km/h）
- 上行车流量
- 下行车流量

#### 3.1.3 交通事件统计

以环形图形式展示当前检测到的交通事件分布，包含：
- 疑似事故
- 异常停车
- 交通阻塞
- 烟雾
- 作业人员
- 其他事件类型

#### 3.1.4 道路通行等级

以等级条形式展示道路通行状态（1-5 级）。

#### 3.1.5 单画面监控

点击顶部导航的「单画面」可切换至单设备全屏监控模式，支持更清晰的视频预览。

---

### 3.2 事件统计

事件统计页面以可视化仪表板形式展示算法检测事件的汇总数据。

#### 3.2.1 筛选条件

- **选择公司**：按分公司筛选（海东分公司、西宁分公司等）。
- **选择区域**：按道路区域筛选（S201、G213 等）。
- **日期范围**：选择统计的开始日期和结束日期。
- 点击「查询」按钮刷新图表数据。

#### 3.2.2 统计图表

页面采用三栏布局展示以下图表：

| 位置 | 图表名称 | 说明 |
|------|----------|------|
| 左上 | 今日上报预警事件数 | 柱状图，展示今日各类型事件数量 |
| 左下 | 今日交通不合规检测 | 柱状图，展示不合规事件统计 |
| 中上 | 算法（场景）监控 | 仪表盘，展示交通检测算法运行状态 |
| 中下 | 算法子场景 | 柱状图，展示各子场景事件分布 |
| 右上 | 算法（场景）趋势 | 折线图，展示事件趋势变化 |
| 右下 | 具体事件趋势 | 折线图，展示选定事件类型的趋势 |

**趋势维度切换**：支持按「时 / 日 / 月」切换趋势粒度。

---

### 3.3 事件管理

事件管理页面用于查看、处置和考核系统检测到的预警事件。

#### 3.3.1 筛选条件

**第一行筛选：**
- 公司名称、区域、算法、事件类型、设备名称

**第二行筛选：**
- 是否合规（是 / 否）
- 处置状态（已处置 / 未处置 / 处理中）
- 开始时间、结束时间

**操作按钮：**
- 查询：按条件搜索事件
- 重置：清空所有筛选条件
- 导出：导出事件列表

#### 3.3.2 视图模式

支持两种视图切换：
- **列表模式**：以表格形式展示事件，包含公司名称、区域、设备名称、算法、事件、处理状态、上报时间、操作等字段。
- **图片卡片模式**：以卡片形式展示事件截图和关键信息。

#### 3.3.3 操作说明

| 操作 | 说明 |
|------|------|
| 详情查看 | 查看事件的详细信息，包括抓拍图片、检测框、事件详情等 |
| 视频回放 | 查看事件关联的视频录像回放 |
| 处置 | 对事件进行处置操作，填写处置结果 |
| 开具考核单 | 对不合规事件开具考核单 |

---

### 3.4 布控管理

布控管理用于配置算法对特定设备的检测任务。

#### 3.4.1 布控列表

表格字段：
- 序号、布控名称、布控设备、算法、创建时间、状态、算法分析状态、操作

#### 3.4.2 新增/编辑布控

1. 点击「新增」按钮打开弹窗。
2. 填写布控名称。
3. 选择算法。
4. 选择服务：从服务列表中勾选需要使用的算法服务。
5. 选择设备：从设备列表中勾选需要布控的设备。
6. 点击「确定」保存。

#### 3.4.3 状态管理

- **启用/禁用**：通过开关切换布控任务的状态。
- **算法分析状态**：展示算法是否在运行中。

---

### 3.5 文件分析

文件分析页面提供录像文件的检索、播放和分析功能。

#### 3.5.1 左侧设备列表

- **道路筛选**：选择道路和路段。
- **关键字搜索**：输入设备名称关键字进行过滤。
- **设备树**：以树形结构展示设备列表，点击选择设备。
- **录像文件列表**：展示选中设备下的录像文件，含文件名称、开始时间、时长。

#### 3.5.2 中间视频播放

- 选择设备和文件后，自动加载视频播放器（HLS 协议）。
- 支持播放/暂停、进度拖动、全屏播放。

#### 3.5.3 右侧分析面板

展示选中文件的分析结果和事件标记。

## 4. 控制台 - 超级管理员

### 4.1 菜单管理

菜单管理用于配置系统左侧导航菜单的结构和属性。

#### 4.1.1 菜单树形表格

以树形表格展示菜单层级结构：
- ID、路由 Name、路由 Path、是否隐藏、父节点、排序、文件路径、展示名称、图标、操作

#### 4.1.2 操作说明

| 操作 | 说明 |
|------|------|
| 新增根菜单 | 创建一级菜单 |
| 新增子菜单 | 在选中菜单下创建子菜单 |
| 编辑 | 修改菜单的属性 |
| 删除 | 删除菜单（有子菜单时需先删除子菜单） |
| 展开/折叠全部 | 一键展开或折叠树形表格 |

#### 4.1.3 菜单属性

- **路由 Name**：Vue Router 的 name 字段
- **路由 Path**：页面访问路径
- **是否隐藏**：控制菜单是否在侧边栏显示
- **父节点**：上级菜单 ID
- **排序**：同级菜单的展示顺序
- **文件路径**：对应 Vue 组件的文件路径
- **展示名称**：菜单在界面上显示的名称
- **图标**：菜单图标标识

---

### 4.2 资源管理

资源管理用于配置系统的 API 接口权限资源。

#### 4.2.1 资源列表

表格字段：
- ID、资源名称、资源分组、请求方式、服务编码、描述、是否隐藏、操作

#### 4.2.2 操作说明

- **新增资源**：填写资源名称、分组、请求方式（GET/POST/PUT/DELETE）、服务编码等信息。
- **编辑资源**：修改已有资源的配置。
- **删除资源**：删除不再使用的资源。

---

### 4.3 微服务管理

微服务管理用于查看和管理系统中注册的后端微服务实例。

- 展示微服务名称、服务地址、状态、注册时间等信息。
- 支持查看服务详情和健康状态。

---

### 4.4 UI 定制

UI 定制用于配置系统的界面主题和样式参数。

- 支持调整主题色、边框样式、布局参数等。
- 修改后实时生效。

---

### 4.5 授权文件

授权文件管理用于上传和查看系统的 License 授权信息。

- **查看授权**：展示当前授权的设备数量限制、有效期等信息。
- **上传授权**：上传新的 License 文件以更新授权。

## 5. 控制台 - 用户中心

### 5.1 用户管理

用户管理以三级树形结构展示公司 → 部门 → 用户的层级关系。

#### 5.1.1 树形结构

```
公司（如：青海海东分公司）
├── 部门（如：技术部）
│   ├── 用户（如：张伟 - 运维管理员）
│   └── 用户（如：王丽 - 普通用户）
└── 部门（如：运维部）
    └── ...
```

#### 5.1.2 搜索条件

- 用户姓名、用户名、手机号、用户角色、账号状态

#### 5.1.3 操作说明

| 操作 | 说明 |
|------|------|
| 新建用户 | 在系统中创建新用户账号 |
| 编辑 | 修改用户信息 |
| 详情 | 查看用户详细信息 |
| 改密 | 重置用户密码 |
| 删除 | 删除用户账号 |
| 展开/折叠全部 | 控制树形表格的展开状态 |

#### 5.1.4 用户信息字段

- 头像、用户名、姓名、工号、手机号、角色、状态

---

### 5.2 组织管理

组织管理用于维护公司的组织架构树。

#### 5.2.1 组织树

左侧以树形结构展示组织架构，支持：
- 添加根节点（创建新公司/顶级组织）
- 添加子节点（在选中组织下创建子部门）
- 编辑节点（修改组织名称等信息）
- 删除节点（删除组织）

#### 5.2.2 组织详情

右侧展示选中组织的详细信息：
- 上级部门、部门名称、部门编码、排序、备注等

---

### 5.3 角色管理

角色管理用于配置系统中的用户角色和权限分配。

#### 5.3.1 角色列表

表格字段：
- 角色 ID、角色名称、角色定义、账号信息、是否使用、使用数量、操作

#### 5.3.2 搜索条件

- 角色 ID、角色名称、角色定义（系统管理员/普通管理员/普通用户/访客）、是否使用

#### 5.3.3 操作说明

| 操作 | 说明 |
|------|------|
| 新增角色 | 创建新角色 |
| 设置权限 | 为角色分配菜单权限和资源权限 |
| 编辑 | 修改角色信息 |
| 删除 | 删除角色（已被使用的角色不可删除） |

---

### 5.4 操作历史

操作历史记录系统中用户的操作日志，用于审计追踪。

- **筛选条件**：用户名、操作类型、操作结果、时间范围
- **记录内容**：用户名、操作动作、IP 地址、操作结果、操作模块、操作时间

## 6. 控制台 - 设备管理

### 6.1 数据源

数据源是系统的核心设备管理模块，用于管理所有接入的视频设备。

#### 6.1.1 数据源列表

表格字段：
- 名称、状态、原始流地址、推流地址、接入方式、坐标经度、坐标纬度、数据源类型、区域、组织、备注、内存使用率、硬盘大小、硬盘使用率、设置

#### 6.1.2 搜索条件

- 数据源名称、接入方式（本地/远程/RTSP/GB28181/ONVIF）

#### 6.1.3 操作说明

| 操作 | 说明 |
|------|------|
| 新增 | 添加新的数据源设备 |
| 编辑 | 修改设备信息 |
| 删除 | 删除设备 |
| 复制流地址 | 点击复制图标可复制 RTSP 地址 |
| 查看更多 | 查看推流地址详情 |

#### 6.1.4 设备状态

| 状态 | 说明 |
|------|------|
| 在线 | 设备正常连接 |
| 离线 | 设备断开连接 |
| 告警 | 设备存在异常 |

#### 6.1.5 使用率展示

内存使用率和硬盘使用率以进度条形式展示：
- 绿色（<= 60%）：正常
- 黄色（60% - 80%）：警告
- 红色（> 80%）：危险

---

### 6.2 设备分组

设备分组用于对数据源进行分组管理。

- **创建分组**：填写分组名称、备注等信息。
- **分配设备**：将数据源添加到分组中。
- **编辑/删除分组**：管理已有分组。

---

### 6.3 区域管理

区域管理用于配置设备所在的地理区域信息。

- 以树形结构管理区域层级（如：省 → 市 → 路段）。
- 支持新增、编辑、删除区域节点。

---

### 6.4 接入协议

系统支持多种设备接入协议，可在「设备管理 > 接入协议」中配置。

#### 6.4.1 GB28181

配置符合 GB28181 国标协议的设备接入：
- SIP 服务器信息配置
- 设备注册管理
- 通道同步

#### 6.4.2 ONVIF

配置支持 ONVIF 协议的设备接入：
- 设备发现
- 参数配置
- 实时预览地址获取

#### 6.4.3 平台列表

管理已对接的第三方平台信息。

---

## 7. 控制台 - 智能联动

### 7.1 联动规则

联动规则用于配置当特定算法事件触发时的自动响应动作。

#### 7.1.1 规则列表

表格字段：
- 状态、联动规则名称、预警级别、算法、事件、是否合规、操作

#### 7.1.2 操作说明

| 操作 | 说明 |
|------|------|
| 新建 | 创建新的联动规则 |
| 编辑 | 修改已有规则 |
| 删除 | 删除规则 |
| 启用/禁用 | 通过开关控制规则是否生效 |

#### 7.1.3 新建联动规则

1. 点击「新建」按钮打开弹窗。
2. 填写联动规则名称。
3. 选择预警级别（全部 / 高 / 中 / 低）。
4. 选择算法（当前支持：交通算法）。
5. 选择事件类型（16 类交通事件）：
   - 疑似事故、作业人员、交通阻塞、异常停车、烟雾
   - 作业车辆识别、非机动车驶入、占用应急车道、逆向行驶
   - 通过卡车数量、通过大客车数量、通过摩托车数量、通过小汽车数量
   - 下行车流量、上行车流量、行人闯入
6. 设置延迟推送（开启后延迟推送告警）。
7. 设置是否合规（全部 / 是 / 否）。
8. 选择单位（隧道所 / 分公司 / 养护中心）。
9. 选择设备：从设备列表中勾选需要监听的设备。
10. 选择推送渠道：
    - 钉钉、钉钉企业群、企业微信、系统提示音
    - API 接口推送、摄像机控制、定制推送渠道
    - Kafka、OA 推送、语音播报、声光报警
11. 点击「立即创建」保存规则。

## 12. 控制台 - 数据清理

数据清理用于配置系统自动清理过期数据的策略。

### 12.1 执行策略

- **立即执行**：提交后立即执行一次清理任务
- **定时执行**：每天按设定时间自动执行清理

### 12.2 执行时间

选择定时执行后，可设置每天的具体执行时间（HH:mm 格式）。

### 12.3 保留设置

| 数据类型 | 说明 |
|----------|------|
| 预警事件保留 | 勾选后设置预警事件的保留天数（1-365 天） |
| 视频文件保留 | 勾选后设置视频文件的保留天数（1-365 天） |

**注意事项：**
- 定时清理任务将在每天凌晨执行，扫描全表数据并分批处理。
- 历史保留时长即数据截止时间，清理时将删除此时间之前的数据。
- 未勾选的数据类型将永久保存，不会被清理。

### 12.4 操作按钮

- **提交执行**：保存配置并触发清理（立即执行模式下）
- **取消**：放弃当前修改

### 12.5 清理记录

页面下方展示历史清理记录，包含：
- 清理时间、清理类型、清理数据量、执行状态、进度

### B. 常见问题

**Q1：为什么某些按钮是禁用状态？**
A：按钮禁用通常有以下原因：当前用户无操作权限、数据状态不满足操作条件（如已删除数据不可编辑）、系统配置限制。

**Q2：如何快速找到目标数据？**
A：使用表格上方的搜索条件进行筛选，支持模糊查询。部分页面支持按多个条件组合查询。

**Q3：数据导出有什么格式？**
A：事件管理页面支持导出功能，导出格式通常为 Excel 或 CSV。

**Q4：删除操作可以恢复吗？**
A：当前系统删除操作不可逆，删除前系统会弹出确认对话框，请谨慎操作。
