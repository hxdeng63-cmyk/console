# AI Console 功能操作手册

## 1. 系统概述

AI Console 是一套面向道路交通智能分析的集中化管理平台，集实时监控、事件预警、设备管理、算法配置、用户权限等功能于一体。

### 1.1 登录

访问系统后进入登录页，输入用户名和密码完成登录。

### 2.2 角色说明

| 角色 | 适用人群 | 权限范围 |
|------|----------|----------|
| **系统管理员** | IT 运维人员、系统负责人 | 拥有系统的所有权限，可进行用户管理、权限分配、系统配置等所有操作 |
| **普通管理员** | 部门主管、班组长 | 拥有部分管理权限，可管理本部门设备和用户，但无法修改系统级配置 |
| **普通用户** | 监控值班人员、操作员 | 拥有查看和日常操作权限，可查看监控、处置事件、导出数据，但无法修改配置 |
| **访客** | 临时查看人员、上级检查人员 | 仅拥有查看权限，无法执行任何修改操作 |

## 3. 业务流程

### 3.1 事件从产生到处置的完整链路

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  设备    │───→│  算法    │───→│  事件    │───→│  联动    │───→│  处置    │
│  采集    │    │  分析    │    │  产生    │    │  推送    │    │  闭环    │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
     │               │               │               │               │
     │               │               │               │               │
     ▼               ▼               ▼               ▼               ▼
 摄像机/视频     交通算法检测     事件列表展示     短信/邮件/     已处置/未处置
 流输入          16类事件识别     实时监控页       弹窗通知       处置状态标记
                                 事件管理页       推送历史记录
```

**流程说明：**

1. **设备采集**：前端摄像机实时采集道路视频流，通过 RTSP/GB28181/ONVIF 等协议接入系统
2. **算法分析**：视频流进入「交通算法」进行智能分析，识别 16 类交通事件
3. **事件产生**：当算法检测到异常时，系统自动生成事件记录，包含时间、地点、类型、截图等信息
4. **联动推送**：如果配置了联动规则，系统会自动通过配置的推送渠道（钉钉/钉钉企业群/企业微信/系统提示音）发送通知给相关人员
5. **处置闭环**：值班人员在「事件管理」中查看事件，进行处置操作，标记处置状态，形成闭环

### 3.2 设备接入流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   添加设备   │───→│   配置接入   │───→│   状态检查   │───→│   视频验证   │
│   信息       │    │   参数       │    │   在线状态   │    │   画面正常   │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
       │                   │                   │                   │
       ▼                   ▼                   ▼                   ▼
  设备名称/所属         接入方式：           数据源列表          实时监控页
  公司/区域/坐标        本地/远程/           状态列显示          选择设备
  备注信息              RTSP/GB28181/        在线(绿色)/         加载视频
                        ONVIF               离线(红色)
```

**操作步骤：**
1. 进入「设备管理 → 数据源」，点击右上角「新增」按钮
2. 在弹窗中填写设备名称、选择接入方式（RTSP/GB28181/ONVIF/本地/远程）
3. 填写对应的流地址（如 RTSP 地址）
4. 选择所属公司和区域
5. 填写坐标（经度/纬度）
6. 点击「确定」保存
7. 在列表中查看设备状态，等待显示「在线」
8. 进入「实时监控」页面，在设备树中选择该设备，验证视频是否正常播放

### 3.3 用户权限分配流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  创建角色    │───→│  分配权限    │───→│  创建用户    │───→│  分配角色    │
│  （可选）    │    │  菜单+资源   │    │  填写信息    │    │  关联角色    │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

**操作步骤：**
1. （可选）进入「用户中心 → 角色管理」，点击「新增角色」
2. 填写角色名称、选择角色定义（系统管理员/普通管理员/普通用户/访客）
3. 在权限树中勾选该角色可访问的菜单和资源
4. 点击「确定」保存角色
5. 进入「用户中心 → 用户管理」，点击「新增用户」
6. 填写用户名、姓名、工号、手机号等基本信息
7. 选择所属公司和部门
8. 为该用户分配角色
9. 点击「确定」完成创建

**左侧 — 设备列表：**
- 以树形结构展示所有设备，按「公司 → 区域 → 设备」层级组织
- 设备前的圆点表示状态：绿色（在线）、灰色（离线）
- 顶部搜索框支持按关键字过滤设备
- 点击设备节点即可在右侧加载该设备的实时视频

**中间 — 视频播放区：**
- 顶部协议切换：flv / vlc 两种协议可选
- 中间为视频画面区域，显示带宽信息和「当前画面：正常画面」叠加信息
- 未选择设备时显示「等待选择设备...」
- 右上角设置按钮可调整播放参数

**右侧 — 报警动态：**
- 顶部筛选下拉框：
  - 报警类型：全部 / 不合规
  - 合规状态：全部 / 合规 / 不合规
- 实时滚动展示最新报警事件卡片
- 每条报警显示：缩略图（含检测框）、时间、事件类型、设备位置、合规状态标签

**操作步骤：**
1. 在左侧设备树中找到目标设备（可输入关键字搜索）
2. 点击设备名称，中间区域自动加载该设备的实时视频流
3. 如视频加载失败，尝试在视频控制栏切换 flv / vlc 协议
4. 右侧实时查看最新报警事件，点击标签页可筛选合规状态

### 4.3 事件管理

事件管理用于查看和处置系统产生的所有预警事件，支持两种视图模式。

```
┌─────────────────────────────────────────────────────────────────────────┐
│  筛选栏（第一行）                                                        │
```

### 14.3 弹窗表单

- 表单填写后点击「确定」保存
- 点击「取消」或右上角关闭按钮放弃操作
- 必填项未填写时，表单会提示校验错误（字段边框变红，下方显示错误信息）
- 表单关闭后再次打开，已填写内容会保留（编辑模式）或清空（新增模式）

### 14.4 搜索筛选

- 多数页面顶部都有搜索栏
- 支持按名称、状态、时间等多维度筛选
- 下拉框支持关键字过滤选项
- 日期选择器支持快捷选择（今天/昨天/最近7天/最近30天）
- 点击「查询」执行搜索，点击「重置」清空所有条件

### 14.5 删除确认

- 所有删除操作均有二次确认弹窗
- 确认弹窗显示被删除对象的名称
- 点击「确定」执行删除，点击「取消」保留数据
- 有关联数据时（如有子菜单的父菜单），系统会阻止删除并提示原因

## 15. 常见问题

**Q1: 实时监控无法加载视频？**
- 检查设备是否在线（数据源列表中状态是否为「在线」）
- 确认设备对应的推流地址是否配置正确
- 尝试切换 flv / vlc 协议
- 检查网络连接是否正常
- 清除浏览器缓存后重试

**Q2: 如何添加新设备？**
- 方式一：进入「设备管理 → 数据源」，点击「新增」按钮，填写设备信息后保存
- 方式二：进入「设备管理 → 设备组管理」，在对应区域下「新增设备」
- 添加后进入「实时监控」验证视频是否正常播放

**Q3: 联动规则没有触发？**
- 检查规则状态是否为「启用」（开关是否为打开状态）
- 确认规则中配置的算法和事件是否正确
- 查看「推送历史」中是否有相关记录
- 检查推送渠道配置是否正确（钉钉/钉钉企业群/企业微信/系统提示音）

**Q4: 如何给用户分配权限？**
- 第一步：进入「用户中心 → 角色管理」，创建或编辑角色
- 第二步：在权限树中勾选该角色可访问的菜单和资源
- 第三步：进入「用户中心 → 用户管理」，编辑目标用户
- 第四步：为用户分配已创建的角色

**Q5: 事件统计数据不准确？**
- 检查筛选条件是否正确（公司、区域、时间范围）
- 确认时间维度选择是否合适（时/日/月）
- 点击「查询」强制刷新图表数据
- 如仍有问题，检查算法服务是否正常运行

**Q6: 忘记密码怎么办？**
- 联系系统管理员
- 管理员在「用户中心 → 用户管理」中找到该用户
- 点击「改密」按钮重置密码
- 通知用户用新密码登录
