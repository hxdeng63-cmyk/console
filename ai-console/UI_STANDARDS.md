# UI 对齐标准

## 验收方式

**截图逐帧对比** —— 每页对照参考截图逐项打勾确认。

---

## 差异四级判定标准

| 级别 | 名称 | 判定条件 | 处理方式 |
|------|------|----------|----------|
| **A** | 功能逻辑矛盾 | 交互矛盾、用户无法完成预期操作 | 必须修，无否决权 |
| **B** | 视觉语义错误 | 视觉表达与参考版明显不一致（颜色含义、按钮类型、层级关系） | 应该修；若 PM 坚持不修，降为「已知偏差」记录 |
| **C** | 纯视觉偏差 | 颜色值/间距/字号与参考版有差异，但语义正确 | 建议修；PM 可接受「当前状态」 |
| **D** | 细节精度差异 | 像素级差异、字号微调 | 可选；主动优化时顺带处理 |

---

## 每页验收清单（截帧打勾）

```
□ 布局结构   — 一/二级菜单、面包屑、按钮位置
□ 颜色值     — 按钮色、边框色、背景色
□ 交互状态   — hover、active、disabled
□ 文字内容   — 中英文、标签名
□ 图标       — 种类、位置
□ 间距       — padding、margin
□ 组件嵌套   — 不出现重复的同级导航元素
□ Tab 行为   — 关闭、回退、激活状态正确
```
